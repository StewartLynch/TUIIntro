# TUIIntro

TUIkit is a brand new Swift framework that lets you build  terminal apps using the exact same declarative syntax you  already know from SwiftUI. In this first video we install  the framework, scaffold a project, and build an interactive  TUI app with state management, text input, theming, and  keyboard navigation — all in pure Swift.
